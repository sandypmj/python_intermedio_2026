  Qué pide el TODO 1

  Hay que crear una herramienta MCP llamada serie(codigo, desde, hasta) que
  descargue del BCRP los datos de una serie y los devuelva ordenados y fáciles
  de usar:

  {
    "codigo": "PN01271PM",
    "nombre": "...",
    "frecuencia": "Mensual",
    "datos": [{"periodo": "2025-01", "valor": 0.5}, ...],  # valor de ejemplo
    "fuente": "https://estadisticas.bcrp.gob.pe/..."
  }

  Paso a paso, debe:
  1. Buscar la ficha: llama a _ficha(codigo) para obtener el nombre y la
     frecuencia. Esta función ya lanza un ToolError con el código si no existe,
     así que conviene llamarla primero.
  2. Preparar las fechas: las convierte al formato que pide la API según la
     frecuencia.
  3. Consultar la API: usa f"{API}/{codigo}/json/{desde}/{hasta}".
  4. Limpiar la respuesta: convierte cada periodo a un formato uniforme, pasa
     cada valor de texto a número y salta los "n.d.".
  5. Resistir los bloqueos: si recibe muchos pedidos seguidos, la API responde
     con una página HTML en vez de JSON. En ese caso hay que esperar unos
     segundos y reintentar, y guardar en caché lo ya descargado.

  Formatos de fecha

  Hay dos conversiones: una para pedir los datos y otra para devolverlos.

  ┌────────────┬──────────────────┬─────────────────┬──────────────────────┐
  │ Frecuencia │ Cómo se pide a   │ Cómo responde   │ Cómo debe devolverlo │
  │            │      la API      │     la API      │         serie        │
  ├────────────┼──────────────────┼─────────────────┼──────────────────────┤
  │ Mensual    │ 2025-1           │ Ene.2025        │ 2025-01              │
  ├────────────┼──────────────────┼─────────────────┼──────────────────────┤
  │ Trimestral │ 2025-1           │ T1.25           │ 2025-T1              │
  ├────────────┼──────────────────┼─────────────────┼──────────────────────┤
  │ Diaria     │ 2025-01-15       │ 01.Oct.26       │ 2026-10-01           │
  ├────────────┼──────────────────┼─────────────────┼──────────────────────┤
  │ Anual      │ 2025             │ 2025            │ 2025                 │
  └────────────┴──────────────────┴─────────────────┴──────────────────────┘

  El código, paso a paso

  1. Tablas de apoyo (líneas 27-29 (mcp/server.py#L27-L29)). MESES traduce cada
  mes a su número e incluye tanto Sep como Set. FECHAS define, por frecuencia,

  2. _fecha_api: la fecha que se pide (línea 87 (mcp/server.py#L87)). Convierte
  tu fecha al formato de la API:
  - 2025-01 pasa a 2025-1.
  - 2025-T1 pasa a 2025-1.
  - Las fechas diarias y anuales quedan igual.
  - Una fecha inválida, como "enero", da un ToolError que muestra los formatos
    correctos.

  3. _anio: los años de dos dígitos (línea 96 (mcp/server.py#L96)). Primero suma
  2000. Si el resultado está en el futuro, resta 100: 26 queda en 2026, y 97
  pasa de 2097 a 1997.

  4. _periodo: el nombre que devuelve la API (línea 102 (mcp/server.py#L102)).
  Separa el nombre por los puntos y lo reordena según la frecuencia:
  - Ene.2025 pasa a 2025-01.
  - 01.Oct.26 pasa a 2026-10-01.
  - T1.25 pasa a 2025-T1.
  - 2025 queda igual.

  5. _periodos: la descarga (línea 115 (mcp/server.py#L115)).
  - Reintentos: hace hasta 4 intentos, con esperas de 0, 5, 10 y 20 segundos.
  - Bloqueos: la API responde con estado 200 aunque envíe HTML, así que el
    estado no sirve para detectarlos. Por eso el código intenta leer JSON: si
    .json() falla con ValueError, reintenta.
  - Errores de red: también se reintentan.
  - Caché: @cache guarda solo las descargas correctas, así que un fallo no queda
    guardado.

  6. serie: la herramienta (línea 127 (mcp/server.py#L127)). Une todo en este
  orden:
  1. Llama a _ficha(codigo), que da el ToolError con XX999 antes de tocar la red
     y aporta la frecuencia.
  2. Arma la URL con las fechas convertidas, y esa URL es también el campo
     fuente.
  3. Recorre los periodos, salta los n.d. y convierte cada valor a float.

  Su docstring también importa: es lo que lee el modelo para saber cómo usar la
  herramienta.

● Qué es alinear periodos

  Dos series no siempre tienen dato en las mismas fechas. Alinear significa
  quedarse solo con los periodos que tienen dato en ambas y emparejar cada valor
  por su fecha, no por su posición en la lista.

  ┌─────────┬──────────┬──────────┬─────────────┐
  │ Periodo │ Serie A  │ Serie B  │  ¿Se usa?   │
  ├─────────┼──────────┼──────────┼─────────────┤
  │ 2025-01 │ 1        │ 1        │ Sí          │
  ├─────────┼──────────┼──────────┼─────────────┤
  │ 2025-02 │ 100      │ sin dato │ No: falta B │
  ├─────────┼──────────┼──────────┼─────────────┤
  │ 2025-03 │ 2        │ 3        │ Sí          │
  ├─────────┼──────────┼──────────┼─────────────┤
  │ 2025-04 │ sin dato │ −50      │ No: falta A │
  ├─────────┼──────────┼──────────┼─────────────┤
  │ 2025-05 │ 3        │ 2        │ Sí          │
  └─────────┴──────────┴──────────┴─────────────┘

  Quedan 3 periodos coincidentes, con A = 1, 2, 3 y B = 1, 3, 2. Sin alinear,
  compararíamos por posición valores de meses distintos, y el resultado no
  significaría nada.

  Qué significa una correlación

  La correlación de Pearson va de −1 a 1 y mide si dos series se mueven juntas
  siguiendo una línea recta.

  ┌───────┬──────────────────────────────────────────────────────────────────┐
  │ Valor │                           Significado                            │
  ├───────┼──────────────────────────────────────────────────────────────────┤
  │ 0.8   │ Relación directa y fuerte: cuando A está por encima de su        │
  │       │ promedio, B casi siempre también.                                │
  ├───────┼──────────────────────────────────────────────────────────────────┤
  │ −0.3  │ Relación inversa y débil: cuando A sube, B tiende a bajar, pero  │
  │       │ con muchas excepciones.                                          │
  ├───────┼──────────────────────────────────────────────────────────────────┤
  │ 0     │ No hay relación lineal, aunque podría existir otro tipo de       │
  │       │ relación.                                                        │
  └───────┴──────────────────────────────────────────────────────────────────┘

  Una correlación de 0.8 no prueba que A cause B. Podría ser al revés, o ambas
  podrían responder a un tercer factor: las ventas de helados y las de
  bloqueador solar suben juntas porque es verano, no porque una cause la otra.

  Decisiones para los casos que tu pedido no define

  - Promedio, primero y último: se calculan solo sobre los periodos
    coincidentes, para comparar las series en igualdad de condiciones.
  - Menos de 2 periodos coincidentes: da ToolError, porque con menos de 2 puntos
    no se puede calcular una correlación.
  - Serie constante en esos periodos: correlacion será None, porque
    matemáticamente no está definida.
  - Frecuencias distintas: se revisan con _ficha antes de descargar nada, y
    serie se usa para los datos.

● Herramienta: es una acción que el modelo decide ejecutar y que puede calcular
  o consultar algo, como resumen o serie.
  Recurso: es información de solo lectura identificada por una dirección, como
  bcrp://serie/PN01271PM; la aplicación o el usuario suele elegir cuándo
  cargarla como contexto.
  Prompt: es una plantilla de instrucciones reutilizable, normalmente elegida
  por el usuario, que no calcula nada por sí misma y solo le indica al modelo
  cómo trabajar.
  En resumen: la herramienta hace, el recurso informa y el prompt guía.
